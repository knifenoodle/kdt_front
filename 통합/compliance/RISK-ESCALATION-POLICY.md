# 위험 발화 에스컬레이션 정책

> `knowledge_base/legal/LEGAL-002_학교폭력예방법_정의.md:29`
> "⚠️ 본 서비스가 실제 학교폭력 정황(따돌림, 반복적 괴롭힘)을 감지했을 때의
> 에스컬레이션/신고 연계 절차는 **별도 정책 문서로 수립 필요**"

**그 문서가 두 소스 어디에도 없었다.** 이 문서가 그것이다.

마이크가 열린 아동 대화형 서비스에서 아이가 실제 피해·자해를 말했을 때 분기가 없다면,
시스템은 **롤플레잉을 계속한다.** 그것이 단일 최대 사고 벡터다.

---

## 1단계 적용 범위

🚨 **현재 마이크는 비활성이다**(D2 — STT 제외). 따라서 이 정책의 **코드 분기는 아직 실행되지 않는다.**

그럼에도 지금 작성하는 이유:
1. STT가 켜지는 순간 이것이 없으면 위 사고가 즉시 가능해진다
2. **골든 픽스처 4문장이 회귀 방지의 핵심**이다 — 지금 고정하지 않으면 나중에 고칠 기준이 없다
3. 심사에서 "실제 학폭·자해를 말하면요?"에 답할 근거가 필요하다

구현 상태:
- ✅ `web/src/lib/riskPatterns.ts` — 사전
- ✅ `web/src/lib/classifyChildUtterance.ts` — 분류기 + exhaustive switch (S9 검사)
- ✅ `web/src/audio/lines.ts` — `escalateSelfHarm` / `escalateGeneral` 문안
- ⬜ 호출부 (STT 활성화 시)
- ⬜ 보호자 알림 채널 (보호자 계정 자체가 미구현)

---

## 핵심 원칙 — 입력측과 출력측은 **정반대**로 동작한다

| | 대상 | 위험 감지 시 |
|---|---|---|
| **출력측** `sanitizeForChild()` | LLM 생성물 | **차단** + 저작 폴백으로 대체. 아이는 아무 일도 없었던 것처럼 진행 |
| **입력측** `classifyChildUtterance()` | 아동 발화 | **차단이 아니라 에스컬레이션.** 세션 중단 + 어른에게 말하기 안내 |

🚨 **같은 사전을 쓰되 동작이 반대다.**
자해를 말한 아이에게 "금지 키워드가 감지되었습니다"로 응답하는 것은
`ETH-002-R6`(수치심 유발 피드백 금지)의 **최악 위반**이다.

원본 코드에는 **입력측이 아예 없다.** `validator.py`는 출력측 전용이다.

---

## 대상 발화 유형

| 분류 | 예시 | 근거 규칙 |
|---|---|---|
| `selfHarm` | 죽고 싶다, 자해했다, 사라지고 싶다, 태어나지 말 걸 | `LEGAL-001` |
| `sexual` | 옷 벗어봐, 야한 사진, 몸 만지기, 성폭력·몰카 | `ETH-002`, `LEGAL-002` |
| `abuse` | 때렸다/맞았다, 협박, 감금, 피가 났다 | `LEGAL-001` |
| `exclusion` | 아무도 말 걸지 마, 우리 반 전체가 안 놀아, 너만 빼고, 따돌림 | `LEGAL-002` |
| `normal` | 그 외 전부 | — |

### 🚨 아동 발화에서 `violence`를 차단하지 않는 이유

아이가 **"쟤가 나 때렸어"** 라고 말하는 것은 **신고이지 위반이 아니다.**
이것을 차단하면 피해 아동의 입을 막는 꼴이 된다.
따라서 `violence` 패턴이 아동 발화에서 걸리면 `abuse`(학대 정황)로 판정해 **에스컬레이션**하며,
결코 "그런 말 하면 안 돼" 류의 응답을 하지 않는다.

## 감지 방식 — 상류 사전의 실측 결함을 보정한다

`rule_engine/validator.py:11-15`는 20단어 부분문자열 매칭이 전부다. 격리 실행 결과:

| 입력 | 상류 결과 | 우리 결과 |
|---|---|---|
| `죽고 싶을 만큼 힘들었어. 자해했어.` | **통과** ❌ 자해 필터 없음 | `selfHarm` → escalate |
| `옷 벗어봐. 야한 사진 보여줄게.` | **통과** ❌ 성적 필터 없음 | `sexual` → escalate |
| `우리 반 전체가 너랑 안 놀 거야. 아무도 말 걸지 마.` | **통과** ❌ 금지어를 안 써서 | `exclusion` → escalate |
| `장애물 달리기를 했어요` | **차단** ❌ `장애` 부분일치 오탐 | `normal` → 통과 |

**보정 내용**
1. 자해·성적·무언어 집단배제 3종 **신설** (상류에 전혀 없음)
2. `장애`·`가난` **제거** — 부분문자열로는 `장애물`·`장애인 배려`·`발달장애 이해` 같은 정당한 용법과 구분 불가.
   이 규칙의 실체는 "차별 표현 금지"이며 프롬프트 규칙(`ETH-002-R1`)과 LLM 판정으로 이관한다
3. 굴절 대응 — 상류의 `때려`는 `때렸`·`때린`을 놓친다 → `때(려|렸|린|리고|릴)`
4. 무언어 집단배제는 키워드로 불가 → **문맥 정규식** (`아무도 .{0,6}(마|않|안)`, `너만 빼고` 등)

**한계 (정직하게)**: 정규식은 한국어 화용을 다 잡지 못한다. 반어·은유·맥락 의존 표현은 통과한다.
실사용 전 **LLM 2차 판정**을 병용해야 한다(G2-6).

## 감지 시 동작

```
아동 발화 → classifyChildUtterance()
   │
   ├─ normal    → 일반 롤플레잉 (respond)
   │
   └─ 위험 4종  → escalate()          🚨 respond() 로는 도달 불가 (S9 검사)
                    ├─ 세션 즉시 중단 (stopSession: true)
                    ├─ 아이에게 안내 문안 재생
                    ├─ 보호자 알림 (notifyGuardian: true)
                    └─ 사람 검토 큐 적재
```

### 아이에게 하는 응답 — 비난 없음

```
selfHarm  →  "지금 이야기는 어른한테 꼭 말해줘. 선생님이나 엄마 아빠한테."
그 외      →  "그건 어른한테 말하는 게 좋겠어. 같이 가서 말해보자."
```

**설계 원칙**
- "잘못했다"는 신호를 절대 주지 않는다. 아이는 옳은 일을 했다 — 말했다
- 빨간색·경고음·오류 화면을 쓰지 않는다(아이 화면에 오류 색 자체가 없다)
- 캐릭터가 계속 곁에 있는다. 화면이 갑자기 닫히지 않는다
- "같이 가서 말해보자" — 아이 혼자 감당하게 두지 않는다

### 보호자 알림

- 알림 시점: **즉시**
- 내용: 발화 원문이 아니라 **유형과 시각**만. 원문 노출 여부는 D5/보관 정책에 따른다
- 채널: 보호자 계정 필요 → **G2-1 선행**

## 🚨 미해결 — 사람의 결정이 필요하다

### 1. 이 경우의 기록 보관
D2로 STT 텍스트를 기본 미보관으로 정했다. 그런데 **위험 발화는 기록해야 보호자가 확인할 수 있다.**
보관 정책과 정면 충돌한다.

| 선택 | 대가 |
|---|---|
| 기록하지 않음 | 보호자가 "무슨 말을 했길래"를 알 수 없다. 알림의 실효성 저하 |
| 유형만 기록 | 절충. 원문 없이 "자해 관련 발화 감지, 8월 5일 14:20" |
| 원문 기록 | 가장 유용하나 별도 동의 + 보관기간 명시 + 삭제 절차 필요 (`LEGAL-003-R4`) |

**권고: 유형만 기록.** 단 이것도 저장이므로 G2-1(동의) 선행이다.

### 2. 도움 연락처 게재 여부
아동 대상 화면에 상담 연락처를 넣을지, 보호자 화면에만 넣을지.
🚨 **게재한다면 반드시 최신 정보를 직접 확인해야 한다.** 이 문서에 연락처를 적어두고 방치하면
잘못된 번호를 아동에게 제시하는 결과가 된다.

### 3. 오탐 처리
정규식은 오탐이 있다. 놀이 맥락의 "죽었다"(게임), "때렸어"(놀이) 등.
오탐으로 세션이 중단되면 아이는 이유를 모른 채 놀이를 잃는다.

**권고**: 오탐 시에도 아이에게 하는 응답은 동일하게 온화하다(비난 없음).
보호자 알림에 "오탐일 수 있음" 표시를 붙이고, 검토 큐에서 사람이 확인한다.

## ⚠️ 과잉 약속 금지

**본 서비스는 법정 신고의무자가 아니다.**

- 아동학대처벌법상 신고의무자는 교사·의료인 등 법이 열거한 직군이며, 앱 서비스는 여기 해당하지 않는다
- 이 정책은 **보호자에게 알리는 것**까지이며, 수사·신고 기관에 직접 연계하지 않는다
- 마케팅·기획 문서에 "학대를 감지해 신고합니다" 류의 표현을 쓰지 않는다 — 지킬 수 없는 약속이며 그 자체가 평판 리스크다
- 탐지율을 수치로 약속하지 않는다. 정규식 기반이며 한계가 명확하다
