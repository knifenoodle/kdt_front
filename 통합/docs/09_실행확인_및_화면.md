## 급한 질문의 답

> 백엔드 팀원의 원본 구조에 내가 만든 프런트가 실행 및 구현 가능한가?

**돕니다.** 코드 수정 없이 `TTORANG_ENGINE` 환경변수만 가리키면 된다.

```bash
export TTORANG_ENGINE="/path/to/Communication_simulator"
./.venv/bin/uvicorn server.app.main:app --host 127.0.0.1 --port 8100
```

| 항목 | 결과 |
|---|---|
| 원본 저장소 | **변경 0건** · HEAD `bdd1bc7` · working tree clean |
| `POST /api/session` | **200 OK** · 3턴 완성 |
| LLM 관통 | 성공 · 6~9초 |
| 계약 일치 | 카테고리 4키 · `Scenario` 6필드 **바이트 동일** |
| 자동 검증 | pytest 56건 · 안전 불변식 14건 |

회귀 방지: `server/tests/test_compat.py` 가 팀원 원본을 무수정 그대로 로드해
계약이 성립하는지 검사한다. 원본이 발전해도 깨지면 바로 잡힌다.

## 캡처 중 발견해 고친 시각 버그 2건

목업 CSS 를 이식할 때 **변환 규칙 두 줄을 빠뜨렸다.** 스크린샷을 찍지 않았으면 못 봤을 것들이다.

### ① 눈썹이 캐릭터 밖으로 날아감

`mockup-v1.html:231` 의 `.brow { transform-box: fill-box; transform-origin: center }` 누락.
없으면 `rotate` 가 SVG 사용자 좌표계 **원점(0,0) 기준**으로 일어나 시루떡 오른쪽 눈썹이
우상단으로 튀었다. → `Character.module.css` 에 추가.

### ② 감정별 눈 크기 변화가 전부 무효

`mockup-v1.html:255-259` 의 `.eye` **적용부**를 빠뜨리고 설정부(`--eye-sx: 1.25` 등)만 이식했다.

```css
.eye {
  transform-box: fill-box; transform-origin: center;
  --eye-sx: 1; --eye-sy: 1; --eye-tx: 0px; --eye-ty: 0px;
  transform: translate(var(--eye-tx), var(--eye-ty)) scale(var(--eye-sx), var(--eye-sy));
}
```

이게 없어서 `listening`(눈 커짐) · `angry`(눈 좁아짐) · `sad` · `scared` · `surprised` 의
눈 변화가 **전부 조용히 무시되고 있었다.** CSS 변수는 정의되지 않아도 오류를 내지 않으므로
빌드·타입체크·불변식 검사 전부 통과했다. **눈으로 봐야 잡히는 종류의 버그다.**

`.tear`/`.sweat` 의 `transform-box` 도 함께 보강했다.

## 두 엔진의 생성 결과 대비

같은 요청, 같은 프런트. **문장만 다르다.**

| | 팀원 원본 (활성 7건) | 우리 사본 (활성 9건) |
|---|---|---|
| `background` | "유치원 자유놀이 시간에 아동이 알록달록한 블록으로 멋진 성을 만들고 있는 **상황입니다**." | "유치원에서 놀고 있어요. 내가 빨간 자동차로 놀고 있어요." |
| 특징 | 문어체, 한 문장 20단어 근접 | 한 문장 10단어 이내로 끊김 |

원인: 사본은 `GDL-001` 을 만 4~6세 기준으로 재작성했고 `ETH-002`·`GDL-001` 을 활성화했다.
원본은 두 문서가 `draft` 라 프롬프트에 도달하지 않는다.

⚠️ 정확히: `GDL-001-R4`(반말 구어체)는 **또래 캐릭터의 대사**에 적용되는 규칙이고
`background` 는 상황 서술이다. 양쪽 모두 `ai_first_message` 는 반말이다
("야호! …쓸게~" / "히히, …붙일 거다~"). R4 는 적용 대상에서 지켜지고 있다.

**차이는 개선이지 비호환이 아니다.** API 계약은 완전히 같고 테스트가 매번 대조한다.
