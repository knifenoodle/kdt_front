### A-2. `rules_index.json:97,109` — draft → active (CS-003)

```
ETH-002:  "status": "draft"  →  "status": "active"
GDL-001:  "status": "draft"  →  "status": "active"
```

severity는 **변경하지 않았다**(ETH-002 `high`, GDL-001 `medium` 유지). 전문가 자문 전이므로 상향 근거가 없다.

**사유 — 비대칭 제거**: `rule_loader.py:41`이 `status != "active"`를 건너뛰므로 이 두 문서의 규칙은 LLM 프롬프트에 **한 번도 도달하지 않았다.** 그런데 `validator.py:14`는 ETH-002 금지어로 생성물을 `critical` 처벌한다. **모델은 기준을 못 듣고 채점만 당하는 구조**였다.

- `ETH-002-R6` — 아동이 실패했을 때도 수치심을 유발하는 피드백이 아니라 재시도를 독려하는 톤
- `ETH-002-R4` — '정답'을 하나로 강요하지 않는다
- `ETH-002-R5` — 도움을 요청할 수 있는 어른이 있다는 메시지 포함
- `ETH-002-R1` — 가해 또래 캐릭터를 악마화하지 않는다
