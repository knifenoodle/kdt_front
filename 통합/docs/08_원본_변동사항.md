## 결론: 원본은 **한 바이트도 바뀌지 않았다**

| 소스 | 절대경로 | 변경 |
|---|---|---|
| 백엔드 | `KDT 해커톤/백엔드/Communication_simulator` | **없음** (working tree clean, HEAD `bdd1bc7`) |
| UI/UX | `KDT 해커톤/uiux기획` | **없음** |

## 대신 어떻게 작업하는가

원본 `Communication_simulator` 를 `frontendbackend/engine/` 으로 **복사**해서 그 사본을 수정한다.

```
KDT 해커톤/
├── 백엔드/Communication_simulator/   ← 원본. 읽기만 한다
├── uiux기획/                          ← 원본. 읽기만 한다
└── frontendbackend/
    ├── engine/     ← 위 백엔드의 사본 (포크 기준 bdd1bc7). 여기서 고친다
    ├── server/     ← BFF
    └── web/        ← Next.js
```

**포크 기록 전문**: `compliance/engine-fork/FORK-LOG.md`
**변경 전 사본**: `compliance/engine-fork/*.upstream` (diff 대조용)

### 전환 경위

당초에는 원본을 직접 수정하되 사본과 기록을 남기는 예외 절차(D4)로 진행했다.
2026-08-05 사용자 결정으로 **"복사해서 작업하고 원본은 원본대로 유지"** 로 전환했고,
원본에 가했던 4건의 수정을 `git checkout -- .` 으로 전부 되돌렸다.

**전환의 이득 3가지**

1. **원본 불가침** — 다른 팀원이 원본을 쓰던 방식이 깨지지 않는다
2. **권한 문제 해소** — "상류 PR 권한 확인 필요"로 막혀 있던 **CS-002·CS-006 을 직접 고쳤다**
3. **우회 장치 제거**

| 제거된 우회 | 대체 |
|---|---|
| `prompt_config` 벤더링 + 모듈 속성 오버라이드 | `engine/prompts/prompt_config.json` 직접 수정 |
| `get_applicable_rules` top_k in-process 래핑 | `engine/rule_engine/rule_engine.py` 직접 수정 |
| 원본 트리 경로 탐색(한글·공백 취약) | 프로젝트 내부 상대 경로 |

**가져오지 않은 것**: `캐릭터_에셋/추출.mjs` — `vm.runInContext` 로 HTML 의 `<script>` 를 실행하고

`mockup-v1.html` 자체도 복사하지 않았다. **읽기 전용 설계 원본 + 시각 회귀 기준**으로 원위치에 남긴다.

`캐릭터연출_기획_v1.md:145/165/185` 의 "사용자 결정 필요" 마커가 stale(같은 파일 `:638` 에서
이미 전부 결정됨)이지만 **수정하지 않았다.** `docs/02` §C 와 `compliance/DECISIONS.md` D7 이
오독 방지 장치 역할을 한다.

## 상류와 다시 맞추려면

```bash
cd "…/frontendbackend"
diff -rq --exclude='.git' --exclude='__pycache__' "../백엔드/Communication_simulator" engine
```

상류가 갱신되면 위 8개 파일의 변경을 다시 적용한다. 변경이 모두 **아동 안전·연령 기준** 때문이므로,
상류에 PR 로 제안하면 이 포크 부채가 사라진다(권한이 생기면).
