# 충돌 해결 매트릭스

`frontendbackend/CLAUDE.md` §3-2의 우선순위 규칙을 각 충돌에 적용한 판정 기록.

**적용 규칙 3단**
1. **데이터 구조·API 계약·필드명·enum·수치 범위** → 백엔드 절대 기준. 예외 없음.
2. **아동 안전·연출·아동 노출 문구** → `uiux기획` 문서 위계 우선 (안전 예외).
3. **백엔드에 개념 자체가 없음** → 판정 대상 아님(부재 ≠ 충돌). 신설하되 "나중에 백엔드가 그 필드를 갖게 되면 어댑터만 삭제" 형태를 유지.
