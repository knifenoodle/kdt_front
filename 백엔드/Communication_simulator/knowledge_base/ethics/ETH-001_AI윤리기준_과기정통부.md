## 요약
과학기술정보통신부가 발표한 「인공지능(AI) 윤리기준」은 최고가치로 '인간성(Humanity)'을 제시하며, 이를 구현하기 위한 **3대 기본원칙**(인간의 존엄성, 사회의 공공선, 기술의 합목적성)과 이를 실천하기 위한 **10대 핵심요건**(인권 보장, 프라이버시 보호, 다양성 존중, 침해금지, 공공성, 연대성, 데이터 관리, 책임성, 안전성, 투명성)을 제시한다.

## 시나리오 생성 시 적용 규칙 (요건별 매핑)

- **[ETH-001-R1] (인간의 존엄성 / 침해금지)** 아동을 실험 대상이 아닌 학습 주체로 다루며, 아동의 감정·자기결정권을 존중하는 방향으로만 시나리오를 설계한다. 아동을 겁주거나 실패를 조롱하는 톤을 금지한다.
- **[ETH-001-R2] (다양성 존중)** 특정 성별, 신체 조건, 가정환경, 장애 여부를 갈등의 원인이나 놀림의 소재로 설정하지 않는다.
- **[ETH-001-R3] (공공성 / 사회공공선)** 시나리오의 학습 목표가 항상 '상호 이해와 건강한 경계 표현'이어야 하며, 보복·회피·무시를 정답처럼 묘사하지 않는다.
- **[ETH-001-R4] (안전성)** 생성된 시나리오는 배포 전 검증기([validator.py](../../rule_engine/validator.py))를 통과해야 하며, 실패 시 자동 재생성 또는 인간 검수로 전환한다.
- **[ETH-001-R5] (투명성 / 책임성)** 각 시나리오가 어떤 규칙(rule id)에 근거해 생성/검증되었는지 로그로 남겨 추적 가능하게 한다.
- **[ETH-001-R6] (프라이버시 보호)** 시나리오 개인화에 사용한 아동 데이터의 근거를 남기되, 실제 원본 발화를 그대로 노출하는 예시를 만들지 않는다(익명화/일반화된 패턴만 사용).
