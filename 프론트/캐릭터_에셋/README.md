# 또랑 캐릭터 에셋

**이 폴더만 있으면 같은 디자인을 어디서든 복원할 수 있다.**
목업(`../mockup-v1.html`)이 사라져도, 작업 기록이 날아가도, 다른 도구로 옮겨가도 마찬가지다.

```
캐릭터_시트.png   한 장으로 전체 보기
svg/             벡터 원본 11종 — 편집·확대 가능, 이게 진짜 원본
png/             투명 배경 512×512 11종 — PPT·피그마에 바로 붙이는 용도
추출.mjs         재생성 스크립트
```

## 3. SVG 안에 뭐가 들어 있나 (중요)

**보이는 게 전부가 아니다.** 각 SVG에는 표정 부위가 **전부** 들어 있고, 지금은
`idle`·무표정 기준으로 일부만 켜져 있다. 파일 맨 위 `<style>` 의 `display` 만 바꾸면
감정 표정을 그대로 재현할 수 있다.

```
입 7종   .m-smile(기본) .m-flat .m-open .m-grin .m-frown .m-wavy .m-o
눈       .eye(기본)  /  .eye-arc (웃는 호 ^ ^)
눈썹     .brows      — 화남에만 쓴다
부속     .blush(볼) .tear(눈물) .sweat(땀) .spark(반짝)
전용     .hand(송편 cantHear) .dots(생각중) .yk-syrup(약과 화해)
        .kk-drip(꿀떡 꿀방울) .honey-coat(무지개떡 꿀 코팅)
        .pat-burst(시루떡 팥고물 6알 — 마음 열릴 때만)
```

예 — 기쁨 표정을 만들려면:
```css
.m-smile{display:none} .m-grin{display:block}
.eye{display:none} .eye-arc{display:block}
.blush{display:block} .spark{display:block}
```
감정 8종의 정확한 조합표는 `../캐릭터_가이드_v1.md` §5.

## 4. 다시 뽑기

```bash
cd 프론트/캐릭터_에셋
node 추출.mjs
```

`../mockup-v1.html` 의 인라인 SVG 함수를 **그대로 실행**해서 뽑는다. 목업의 캐릭터를
고치면 이 명령 한 번으로 에셋이 따라온다. 손으로 두 벌 관리하지 않는다.

PNG 생성에는 Chrome이 필요하다(경로는 스크립트 상단 `CHROME` 상수). 없으면 SVG만 나온다.

## 5. 쓸 때 지킬 것

- **송편 기본값은 반드시 쑥색(녹색)이다.** 분홍은 아이가 고르는 선택지일 뿐,
  기본값으로 올리거나 성별을 암시하는 데 쓰지 않는다 (근거: `../작업기록_UIUX_v1.md` §7)
- **시루떡을 악당처럼 그리지 않는다.** 소통이 서툴러 툴툴대는 캐릭터다.
  뿔·송곳니·찡그린 붉은 얼굴 금지
- **캐릭터를 검정·갈색·회색으로 어둡게 칠하지 않는다** (`../CLAUDE.md` 3절)
- 몸통은 저채도, 포인트 하나만 고채도 — 이 대비가 떡 캐릭터의 핵심이다
