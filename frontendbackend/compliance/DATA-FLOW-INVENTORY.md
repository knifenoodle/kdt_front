# 데이터 흐름 인벤토리

처리방침(`PRIVACY-POLICY-DRAFT.md`)의 근거표.
**"아이 목소리가 어디로 갑니까"는 심사에서 나올 확률이 높은 질문이다.** 이 문서가 답이다.

## 한 줄 요약

> **1단계에서 아동의 음성·발화는 기기를 떠나지 않는다.** STT를 범위에서 제외했기 때문이다(D2).
> 현재 국외로 나가는 것은 **운영자가 선택한 카테고리 키와 연령대 밴드**뿐이며, 둘 다 개인정보가 아니다.

### 🚨 수집하지 **않는** 것 (스키마 차원에서 부재)

`name` · `nickname` · `birthdate` · `birth_year` · `child_id` · `school` · `grade` · `gender` · `phone` · `email` · `address` · 정수 나이

근거: `프론트/CLAUDE.md:107` — "아이 온보딩에서 이름·생년월일을 받지 않는다. 필요한 건 연령대(4/5/6세)뿐."
강제: `server/app/schemas.py` `SessionRequest`가 `extra='forbid'`. 주입 시 **422 거부**(실측 4/4).
회귀 방지: `server/tests/test_contract.py::test_request_rejects_pii_fields` (12개 필드 파라미터화)

### 저장소 현황

| 종류 | 상태 | 검증 |
|---|---|---|
| DB (sqlite/postgres/redis) | **없음** | 원본·통합 양쪽 grep 0건 |
| 세션·쿠키·인증 | **없음** | 동일 |
| `localStorage`/`sessionStorage`/`indexedDB` | **없음** | `check-safety-rules.mjs` S6 |
| 파일 쓰기 | **없음** (원본은 `print()`만, 그것도 examples/) | grep |
| 로깅 프레임워크 | 원본 **없음**. BFF는 `logging` 사용하되 **요청 본문을 기록하지 않는다** | `server/app/` |
| 음성 녹음 파일 | **없음** (마이크 비활성) | D2 |

**결론**: 1단계는 **완전 무상태**다. 동의 의무가 발생하는 저장 행위 자체가 없다.

## 보관 정책 (D2 기준)

**오해 정정**: `프론트/CLAUDE.md:110`(즉시 파기)과 `LEGAL-003-R4`(보관기간 명시)는 **충돌이 아니다.**
R4는 *"보관한다면* 기간을 명시하고 열람·정정·삭제 절차를 마련하라"는 **조건부 규칙**이며,
즉시 파기는 **"보관기간 = 0초"로 명시함으로써 R4를 만족**한다.

진짜 충돌은 다른 곳이다 — **즉시 파기 ↔ 부모 리포트(`README.md §2-③`)의 증거 기반**.
D5로 지수 리포트를 유지하기로 했으므로 아래로 분리해 해소한다.

| 항목 | 보관기간 | 비고 |
|---|---|---|
| 오디오 원본 | **0초 (저장하지 않음)** | 어느 분기에서도 저장하지 않는다. 유출 시 회복 불가한 평판 손상 |
| STT 텍스트 | 기본 **미보관**. 보호자 옵트인 시 N일 | 옵트인이 G2-1(동의 플로우) 없이는 불가능 |
| 리포트 집계값 | 보호자 계정 유지 기간 | G2-4(보호자 인증) 선행 |
| 서버 로그 | 요청 메타만. **본문 미기록** | 상관 ID로 추적 |

상세는 `RETENTION-DELETION.md`.

## 데이터 흐름도 (1단계 실제)

```
[아이]  탭 1회 (마이크 비활성)
   │
   ▼
[브라우저]  Web Speech TTS (온디바이스 우선)  ← 캐릭터 대사만
   │  fetch /api/session  { category, age_band, scene }   ※ 아동 식별정보 0개
   ▼
[Next.js :3000]  rewrites 프록시 (동일 오리진)
   │
   ▼
[BFF :8100]  Literal 검증 → age_band를 서버 정의 라벨로 번역
   │  in-process import (읽기 전용)
   ▼
[rule_engine]  규칙 9건 주입 → 프롬프트 조립
   │
   ▼
[Google Gemini]  ◀── 🚩 국외이전 지점. 전송: 규칙 문서 + 카테고리 + 연령대 라벨
   │                                    미전송: 아동 발화·이름·생년월일
   ▼
[validator]  금칙어 검사 → 통과분만
   │
   ▼
[TemplateDeckAdapter]  ai_first_message 1줄만 주입, 나머지 14줄은 저작 데크
   │
   ▼
[sanitizeForChild]  🚩 아동 안전 관문 — 위험·과길이는 저작 폴백으로 대체
   │
   ▼
[아이의 귀]  TTS
```

**저장 지점 0개.** 위 경로 어디에도 디스크·DB 쓰기가 없다.
