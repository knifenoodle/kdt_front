# 문서 안내 — 뭘 어디서 찾나

이 저장소에는 문서가 많다. **이 파일 하나가 전체 지도**다. 처음이면 위에서부터 순서대로,
급하면 "지금 실행하기"만 보고 나머지는 필요할 때 찾아오면 된다.

---

## 지금 실행하기

터미널 두 개가 필요하다. 첫 번째는 서버(BFF), 두 번째는 화면(웹)이다.

### 터미널 1 — 서버

```bash
cd frontendbackend
python3 -m venv .venv
./.venv/bin/pip install -r server/requirements.txt

export GEMINI_API_KEY='발급받은 키'   # 없어도 동작한다 — 아래 "키 없이도 되나요?" 참고
./.venv/bin/uvicorn server.app.main:app --host 127.0.0.1 --port 8100
```

### 터미널 2 — 화면

```bash
cd frontendbackend/web
npm install
npm run build
npx next start -p 3000
```

빌드 없이 빠르게 확인만 하고 싶으면 `npm run build && npx next start` 대신 `npm run dev`를 써도 된다
(둘 다 확인됨. dev가 조금 더 빠르게 뜨고, start는 실제 배포와 더 가깝다).

### 주소

| 주소 | 무엇인가 |
|---|---|
| **http://127.0.0.1:3000** | 실제 서비스 화면. 여기를 연다 |
| http://127.0.0.1:3000/api/health | 서버가 잘 떠 있는지, 어느 규칙 엔진을 쓰는지, 키가 있는지 확인 |
| http://127.0.0.1:3000/__dev | 개발자용 확인 화면 (카테고리별 응답을 직접 눌러 확인). **아이가 보는 화면이 아니다** |

브라우저는 3000번 주소 하나만 열면 된다. 화면(웹)이 `/api/*` 요청을 자동으로 8100번 서버로
전달해주기 때문에 두 서버가 다른 포트에 떠 있어도 브라우저 입장에서는 신경 쓸 게 없다.

### 키 없이도 되나요?

된다. `GEMINI_API_KEY`를 안 주고 켜도 화면은 끝까지 정상적으로 돈다 — AI가 만든 문장 대신
미리 써둔 문장으로 채워질 뿐, 아이 화면에서는 차이가 보이지 않는다. 서버 켤 때 로그에
"GEMINI_API_KEY 가 없습니다"라고 뜨는데, 이건 정상이다(오류 아님).

### 빨리 확인하는 법 (터미널만으로)

```bash
cd frontendbackend/web
node scripts/capture-full-session.mjs 3000
```

브라우저를 안 열어도 이 명령 하나가 시작 화면부터 3턴 대화, 보상 화면, 다시 시작까지
전부 자동으로 눌러보고 결과를 터미널에 찍어준다. 화면 캡처(스크린샷)도 `docs/screenshots/`에 남는다.

### 팀원 백엔드 코드로 바꿔서 테스트하려면

```bash
export TTORANG_ENGINE="/path/to/Communication_simulator"
```

이 환경변수를 서버 켜기 전에 설정하면, 우리가 고친 사본(`engine/`) 대신 팀원의 원본 코드를
그대로 가져와서 돌린다. 지정하지 않으면 자동으로 저장소에 포함된 사본(`engine/`)을 쓴다.

## 폴더 하나로 요약하면

```
frontendbackend/
├── README.md              ← 실행 명령어 + 프로젝트 요약
├── 문서_안내.md            ← 지금 보고 있는 파일
├── CLAUDE.md               ← 작업 원칙
│
├── docs/                   ← "왜 이렇게 만들었나" 기록
├── compliance/              ← 아동 안전·법적 검토 (가장 많은 문서)
├── contracts/               ← 기계가 읽는 데이터 규격
│
├── engine/                  ← 규칙 엔진 (원본 백엔드의 사본 — 여기서 고쳤다)
├── server/                  ← 중간 서버(BFF). 화면과 engine/ 을 이어준다
└── web/                     ← 실제 눈에 보이는 화면 (Next.js)
```

**막히면**: `README.md` 상단 표에서 짧게 훑고, 이 파일에서 관련 항목을 찾아 들어가면 된다.
