## (2) 🚨 부정 경로 — 여기가 진짜 검증이다

**합격선: API 키가 죽어도 아이 화면이 아무 차이 없이 끝까지 돈다.**

```bash
# 키 없이 재기동 후
curl -s -X POST :8100/api/session -H 'Content-Type: application/json' \
  -d '{"category":"ownership_turn","age_band":"5"}' | jq '.source, (.turns|length)'

# 미지 카테고리
curl -s -X POST :8100/api/session -H 'Content-Type: application/json' \
  -d '{"category":"bogus","age_band":"5"}' -w '\n%{http_code}\n'

# 아동 식별정보 필드 주입 (M7)
for f in name birthdate child_id school grade gender; do
  curl -s -o /dev/null -w "$f %{http_code}\n" -X POST :8100/api/session \
    -H 'Content-Type: application/json' \
    -d "{\"category\":\"ownership_turn\",\"age_band\":\"5\",\"$f\":\"x\"}"
done

# 미구현 카테고리
curl -s -X POST :8100/api/session -H 'Content-Type: application/json' \
  -d '{"category":"verbal_discomfort","age_band":"5"}' -w '\n%{http_code}\n'
```
